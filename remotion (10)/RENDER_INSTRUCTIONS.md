# Render instructions

1. Place `remotion (10)` directly inside the GetVideosLocally repository root.
2. Run `npm install`.
3. Run `npm run studio`.
4. The pre-Studio asset sync copies the authentic GetVideosLocally screenshots, logo and Manrope font from the parent repository.
5. Open composition `ProductDemo`.
6. Do not replace screenshots or reconstruct missing application UI.
7. For a final MP4, run `npm run render`.

Composition: `ProductDemo`
Resolution: 1920×1080
FPS: 30
Duration: 45 seconds / 1350 frames
