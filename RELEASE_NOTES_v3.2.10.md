# GetVideosLocally v3.2.10

## Security: Electron 44

- The app now runs on Electron 44.9.3 (Chromium 152). Electron 42, which earlier versions used, no longer receives security fixes.
- Nothing changes in how the app looks or works.

Thanks to @egmtm for the upgrade (#3).

## Downloads

Use the Windows installer to update an existing installation, or extract the portable ZIP and run GetVideosLocally.exe.

Completed downloads, history, and settings are preserved when upgrading.
